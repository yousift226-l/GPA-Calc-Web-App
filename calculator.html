GPA Calculator

Calculate your cumulative GPA

How to use

Simply select from the "Grade" dropdown box what grade you have for the class in mind. Then type the credit hours that apply to that same course. After you have provided the necessary data click on the "Calculate GPA" button to instantly see your GPA. Final note, If you have more classes you need to add just press the "Add Class +" button.

Letter Grade Scale

• A = 4.0

• B = 3.0

• C = 2.0

• D = 1.0

• F = 0
