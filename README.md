# GPA Calculator & Academic Assistant

A full-stack web application designed to help students calculate their GPA and interact with an AI-powered academic assistant. This project was built from the ground up to focus on clean logic, efficient rendering, and seamless API integration.

## Features

*   **GPA Calculation:** Accurate weighting and calculation for semester and cumulative grades.
*   **AI Chatbot Integration:** A built-in AI assistant to answer academic questions and provide guidance.
*   **Responsive UI:** A clean, minimal interface built without heavy external frameworks.
*   **Node.js Backend:** Handles API communication and server-side logic securely.

## Tech Stack

*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
*   **Backend:** Node.js, Express
*   **AI:** Generative AI API Integration
*   **Environment Management:** Dotenv for secure API key handling
